# AJAX-механики: этап 3 — проверки и регрессии

Дата: 2026-10-14. Автоматические и live HTTP-проверки выполнены.
Согласованные проходы во встроенном браузере и через Playwright остаются
открытыми из-за ошибок запуска инструментов; этап полностью не закрыт.

## Изменения

1. Исправлена статистика, из-за которой реальная главная страница возвращала
   HTTP 500 (`sqlalchemy.exc.AmbiguousColumnError` для `owner_id`). В базовом
   запросе фильтры привязаны к колонкам модели явно; агрегаты имеют основной
   FROM. LEFT JOIN включает эпизоды без аудиофайла; пустые суммы равны нулю.
2. Заглушка `downloading_count=125` заменена числом активных эпизодов владельца.
   Добавлены два теста статистики на изолированной PostgreSQL: пустой набор,
   эпизоды с аудио и без него, владение, счётчик загрузок и изменение после
   удаления. Unit-тесты статистики переведены на строгие autospec mocks.
3. Запоздавшие fragment-ответы сравниваются с текущим URL: ответ для старых
   фильтров не заменяет актуальную страницу. Добавлены JS-проверки этой гонки,
   паузы в скрытой вкладке, backoff и отсутствия параллельного polling.
4. Стенд `browser_app.py` поддерживает отдельный BROWSER_PORT, включая media
   URLs. Старый сервер на 8019 не использовался для итогового HTTP-прохода.
5. Добавлен явный live HTTP smoke runner
   `src/tests/frontend/live-http-smoke.cjs`. Он работает только с loopback и
   проверяет test-only feed перед изменением данных; не запускается как часть
   обычных unit-тестов и не исполняет фронт в браузере.

## Live HTTP-проход

Свежий сервер запущен на `http://127.0.0.1:8037/`, база
`podcast_ajax_browser_stage3_final_20261014`. Использованы реальная
авторизация, маршруты, PostgreSQL, шаблоны, media token redirects и fake
границы очереди/Redis/storage/media source.

Пройдено восемь групп проверок:

- вход с session cookie;
- рендер основных страниц;
- валидация, создание и редактирование подкаста, escaping кавычек и HTML;
- медленный источник, автозагрузка, отмена, 409 при удалении активного
  подкаста, повтор создания без дубликата и редактирование эпизода;
- завершение загрузки, отсутствие эпизода в активном progress, media redirect,
  доступность WAV и появление audio element в серверном фрагменте;
- завершение RSS-задачи, доступность XML и счётчик эпизодов;
- удаление эпизода и подкаста, пустой список, нулевой счётчик и 404;
- отсутствие session cookie: 401 JSON без редиректа.

Артефакт: `output/playwright/stage3-live-http.json`. Исправленный runner
повторно прошёл после корректировки проверяемого source URL и проверки
loopback-origin media redirects. Созданные им сущности удалены. Схема и
seeded account/podcast оставлены в выделенной тестовой базе; production-данные
не использовались.

## Браузеры и оставшиеся ограничения

Встроенный инструмент повторно завершился до чтения UI: Node не может
прочитать `/System/Library/OpenSSL//openssl.cnf` (`Operation not permitted`).
Playwright CLI дважды завершился при запуске установленного Chrome с
`SIGABRT`, включая повтор после запроса расширенного доступа. Ошибки запуска
не являются результатом тестирования приложения в браузере.

Скриншоты, успешные traces и реальные UI-сценарии отсутствуют.
HTTP/JS-проверки не подтверждают реальное воспроизведение аудио, визуальное
ожидание и ошибки, отсутствие перезагрузок при кликах, работу CSS, фокус,
сохранение плеера/прокрутки в браузере и все сценарии сетевого перехвата.

Диагностика: `output/playwright/stage3-browser-blockers.txt`.
Сценарии для обоих независимых проходов:
`output/playwright/stage3-browser-scenarios.md`.

Осталось восстановить запуск встроенного браузера и Chrome/Playwright,
выполнить эти сценарии, сохранить реальные артефакты и исправить найденные
регрессии. P6 остаётся открытым: P6b не расширялся до полного покрытия всех
HTML views. Коммиты и push агент не выполнял.
