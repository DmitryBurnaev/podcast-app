# Открытая браузерная проверка

Эти сценарии **не выполнены**: встроенный браузер и Chrome через Playwright
завершаются при запуске. HTTP-проход и JS unit-тесты описаны отдельно.

## Изолированный стенд

Приложение: `src.tests.browser_app:make_browser_app`, отдельная PostgreSQL с
именем, начинающимся с `podcast_ajax_browser_`. Для нового стенда необходимо
использовать новый TEST_DB_NAME. Порт uvicorn должен совпадать с BROWSER_PORT.
Тестовый аккаунт: `browser@podcast.example` / `browser-check`.
Внешние зависимости подменены stateful fakes. Создание эпизода задержано на
4 секунды; завершение загрузки — на 5 секунд, RSS — на 4 секунды.

Пример запуска (DB_PASSWORD передаётся отдельно через окружение):

```sh
env TEST_DB_NAME=podcast_ajax_browser_manual BROWSER_PORT=8037 .venv/bin/uvicorn src.tests.browser_app:make_browser_app --factory --host 127.0.0.1 --port 8037
```

Playwright CLI: открыть `http://127.0.0.1:8037/login`, получить snapshot и
работать с актуальными element refs. Сохранять screenshots/traces здесь.
Для встроенного браузера выполнить независимый проход по тому же стенду.

## Сценарии и ожидаемые результаты

| Сценарий | Ожидаемый результат |
| --- | --- |
| Создать подкаст с кавычками и HTML-символами в названии | Карточка добавляется без перезагрузки, текст отображается безопасно, автозагрузка выключена |
| Изменить имя, описание и автозагрузку | Форма, карточка, заголовок и breadcrumbs согласованы после ответа |
| Создать эпизод по `https://www.youtube.com/watch?v=stage3demo0` | В модалке видны ожидание и блокировка действий; после успеха появляется карточка |
| Двойной клик/повтор Enter во время запроса | Один изменяющий запрос; блокировка сохраняется до обновления фрагментов |
| Ошибка валидации, HTTP 500/503, offline или таймаут | Ошибка внутри формы/диалога, ввод сохранён, повторный запрос не отправляется автоматически |
| Запуск и отмена загрузки | Видны промежуточные состояния; завершение показывается после подтверждения бека |
| Конечное состояние загрузки | Карточка/метаданные и счётчики обновляются; опубликованное аудио воспроизводится |
| Генерация RSS | Видно ожидание фоновой задачи, ссылка появляется после success; ошибка задачи показывается безопасно |
| Удаление подкаста с активным эпизодом | Диалог показывает 409, карточки и данные сохраняются |
| Удаление из списка и со страницы детали | Карточка исчезает либо выполняется переход к списку; пустые состояния и счётчики обновляются |
| Unsaved поля, прокрутка и работающий плеер при refresh | Ввод и позиция прокрутки сохраняются, прежний audio element продолжает воспроизведение |
| Фильтры и запоздавший ответ | Старый fragment не заменяет данные нового URL; повторное открытие фильтров показывает текущие значения |
| Скрытая вкладка и сетевой сбой polling | Новые запросы приостановлены; после возвращения polling возобновляется, после ошибки применяется backoff |
| Истёкшая сессия | Сообщение со ссылкой на вход; повторная мутация заблокирована, ввод сохранён |
| Escape/Tab, восстановление фокуса, reduced motion | Модалки управляются клавиатурой, фокус возвращается, анимация учитывает настройку ОС |

Для сетевых ошибок и задержек использовать DevTools или перехват запросов
Playwright; не менять production-контроллеры ради ошибок стенда.
